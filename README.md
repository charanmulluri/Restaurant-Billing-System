Restaurant Billing System

About the Project

This is a Python-based Restaurant Billing System. It helps display the food menu, take customer orders, calculate bills, generate receipts, and show daily sales.

Features

* Display Food Menu
* Add Food Items
* Take Customer Orders
* Calculate Bills
* Apply Discounts
* Generate Receipts
* View Daily Sales

Programming Language

Python 3

Concepts Used

* Lists
* Tuples
* Loops
* Functions
* Conditional Statements
* Exception Handling

Discount Rule

A 10% discount is applied when the subtotal is Rs.500 or more.

How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the Python file.
4. Open the VS Code Terminal.
5. Run this command:
    python Restaurant_Billing_System.py
